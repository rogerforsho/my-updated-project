# Roles and Permissions

The application has four user-facing roles: OJT Student, Supervisor, OJT Coordinator, and Super Admin. The database may retain compatible role identifiers during migration, but OJT Staff and Program Head are not application roles. Students use the mobile app only. Supervisors, OJT Coordinators, and Super Admins use the web portal or desktop wrapper. Access is denied unless explicitly allowed.

| Capability | OJT Student | Supervisor | OJT Coordinator | Super Admin |
|---|---|---|---|---|
| Register and view own records | Yes, mobile only | No | No | No |
| Submit own attendance, requirements, and reports | Yes, mobile only | No | No | No |
| Review attendance | No | Assigned trainees | Scoped exceptions | No |
| Approve or return daily accomplishment reports | No | Assigned trainees | Academic oversight | No |
| Approve student registration and requirements | No | No | Granted departments | No |
| Manage HTEs, branches, supervisors, and placements | No | No | Granted departments | No |
| Submit supervisor evaluations | No | Assigned trainees | No | No |
| Assign final OJT grade and review academic completion | Own results | No | Granted departments | No |
| View department reports | No | No | Granted departments | No |
| Chat with eligible counterpart | No | Assigned trainees | Active department-linked placements | No |
| Manage accounts and system settings | No | No | No | Yes, with MFA |
| Review security audit metadata and account events | No | No | No | Yes, with MFA |
| Access routine academic records, student files, attendance, or chat content | Own records only | Assigned trainees | Granted departments | No |

OJT Coordinator grants are stored in `staff_capability_grants`; a Coordinator may have ICS, IBE, or both. Academic student records are restricted by the student's course department at the database boundary. Supervisors remain limited to assigned trainees. Super Admins are individually invited accounts, must use MFA, and deactivate accounts without deleting their OJT history. Provider backups and restores remain outside the application; the application must not export academic records to an administrator workstation. IT evaluators are external reviewers, not an application role.
