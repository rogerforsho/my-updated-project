# Overview

This wiki organizes project reference material so it can be found and consulted consistently. It records information from real project sources and links wiki notes back to the material they summarize.

## How sources are added

Add source material under `LLM-Wiki/raw/` without inventing or silently changing its contents. Give each source a clear filename. Create a corresponding note under `wiki/sources/` that identifies the source and summarizes only what it supports.

## How notes are organized

Use `wiki/sources/` for notes about individual source materials, `wiki/entities/` for notes about named people, organizations, systems, or other entities, and `wiki/concepts/` for notes about recurring ideas or terms. Link related notes to one another and include source references for factual claims. Update the index and log when the wiki structure or content changes.
